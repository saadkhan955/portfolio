# Saad Khan — Enterprise Frontend & Drupal Specialist Portfolio

A modern, high-performance developer portfolio showcasing verified enterprise Drupal architectures, modern React/TypeScript applications, Chrome Extensions, and mobile engineering.

Built with **React 19**, **TypeScript**, **Vite 8**, **Tailwind CSS v4**, and **Lucide Icons**.

---

## 🌟 Featured Highlights

- **Enterprise Drupal 10/11 Architecture**: RAF Benevolent Fund, Adder Technology, Leonard Cheshire, CLPE, RCoA CPOC, Framestore, Kick It Out.
- **Modern Full-Stack & SPAs**: Icare Water Solutions AquaSuite ERP, Mystic Favicon Studio, Ainexorium EdTech, Elite Launchpad, Daftar.
- **Browser Extensions & Native Mobile**: TabFlow for YouTube (MV3), Tab URL Copier, PassPic AI (Offline ML Kit Flutter), Automatic Mouse Mover (macOS Cocoa).
- **Interactive Deep Dives**: Search filter by tech stack or JIRA ticket, architectural case studies, performance metrics, and embedded PDF resume viewer.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 8
- **Styling**: Tailwind CSS v4 + Plus Jakarta Sans & JetBrains Mono typography
- **Iconography**: Lucide React SVG icons (Zero unicode emojis)
- **Design Principles**: WCAG 2.1 AA accessibility, high contrast, zero CLS, mobile-first responsive layout

---

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation & Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
